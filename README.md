## Contexte du Projet

**IdleMon** a été développé en Kotlin sur Android Studio dans le cadre de la ressource *Développement Mobile* (2ème année du BUT Informatique à l'IUT de Laval). 
Le projet a été récompensé par la note de **20/20** ! 🎉

## Fonctionnalités Principales

- **Système RogueLike** : La mort n'est qu'un début. Chaque partie vous permet d'améliorer vos statistiques et vos chances pour la run suivante.
- <img width="24" alt="pokeball" src="https://github.com/user-attachments/assets/b5adeb39-9e32-4c80-b5b4-cef219f95eec" /> **Création d'équipe** : Construisez et optimisez votre propre équipe pour trouver la synergie parfaite.
- <img width="24" alt="loupe" src="https://github.com/user-attachments/assets/074fc5dd-deab-45ef-9ce5-3c6d15867bcc" /> **Capture de Pokémon** : Agrandissez votre collection en capturant de nouveaux monstres au fil de votre aventure.
- <img width="24" alt="combat" src="https://github.com/user-attachments/assets/7e358a87-34f7-4803-8ec4-e683b5f73b3e" /> **Vagues infinies** : Testez vos limites et votre stratégie dans un mode de combat continu où la difficulté ne cesse de croître.
